### Sistema de Alunos 2.0
Sistema completo para gerenciamento de alunos com as funcionalidades:

| Funcionalidade | Descrição |
|----------------|-----------|
| Cadastro | Adicionar aluno com nome e notas |
| Listagem | Exibir todos os alunos cadastrados |
| Média | Calcular média individual de cada aluno |
| Situação | Aprovação (média ≥ 6) ou reprovação |
| Melhor Aluno | Identificar aluno com maior média |
| Estatísticas | Total de alunos, média da turma, aprovados/reprovados |

**Tecnologias:** Python, funções, dicionários, listas, validação com try/except
